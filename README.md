# NutriBudget: A personalized meal recommendation system using Fuzzy Logic and Genetic Algorithm

NutriBudget aims to help university students select their meals that balance their daily food budget, nutritional needs and food preferences using Fuzzy Logic.

## Problem Statement
University students often have limited daily food budgets and may find it difficult to choose meals that are nutritionally suitable. Limited food budgets and different health goals can make daily meal selection challenging. This leads students to prioritize affordability over nutritional needs when selecting their daily meals.

## Proposed Technology
Fuzzy Logic

## Target Users
- University students
- Campus café owners
