# NutriBudget: A personalized meal recommendation system using Fuzzy Logic and Genetic Algorithm

A Fuzzy Logic-based meal recommendation system for university students based on budget, nutritional needs and personal health goals.

## Problem Statement
University students may find it difficult to choose meals that are both affordable and nutritionally suitable. Limited food budgets and different health goals can make daily meal selection challenging.

## Proposed Technology
Fuzzy Logic

## Target Users
- University students
- Campus café owners

## Project Status
Planning and documentation phase.
