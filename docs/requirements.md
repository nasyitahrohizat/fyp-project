
# Requirements

## Functional requirements (what the system must DO)

1. FR1: The system shall allow students to enter their daily food budget in RM.
2. FR2: The system shall allow students to select their health goal, such as losing, gaining, or maintaining weight.
3. FR3: The system shall allow café owners to add menu items with their prices and nutritional information.
4. FR4: The system shall use Fuzzy Logic to calculate meal suitability based on budget, nutrition, and health goals.
5. FR5: The system shall display a ranked list of recommended meals that fit student's daily food budget.

## Non-functional requirements (how the system must PERFORM)

1. NFR1: The system shall display meal recommendations within 3 seconds for a list of up to 100 items.
2. NFR2: The system shall require café owners to log in before they can update menu informaion
3. NFR3: The system shall display error message when a user leaves a required field empty.
