
# User Stories

1. As a student, I want to set my daily food budget, so that I can choose meals within my budget. (FR1)

   Acceptance Criteria:
   - Students can enter and save their daily food budget.
   - The system shows an error message if the budget is empty or invalid.

2. As a student, I want to get meal recommendations based on my budget and nutritional needs, so that I can make better food choices and thus stay healthy. (FR5)

   Acceptance Criteria:
   - The system only recommends meals within the student's budget.
   - The system displays the recommended meals in ranked order based on their suitability.

3. As a café owner, I want to add food items with their prices and nutritional information, so that students can see the available meal options. (FR3)

   Acceptance Criteria:
   - Café owners can enter food names, prices, and nutritional information.
   - The added food items appear in the menu after being saved.
